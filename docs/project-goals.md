# Project goals

## G001 — Accurate public project portfolio

Present each selected open-source project with its purpose, intended capabilities, honest current state,
source link, implementation context, and representative media in a clear responsive portfolio.

## G002 — Central browser release host

Publish each project's verified asset-free WebAssembly package under this site's project route, and
refresh its portfolio information whenever the source project releases. The source project remains the
build and capability-evidence authority; this repository owns deployment and live links. Never host
game files, saves, or derived restricted inputs.
